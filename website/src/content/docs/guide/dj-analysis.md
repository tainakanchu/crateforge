Crateforge は **純 Rust の DSP** で DJ 向けの音声解析を行います。
外部ツールに依存せず、**BPM / Key (Camelot) / Energy / ラウドネス** と類似度ベクトルを推定します。

> 画像は後日追加

## 何が解析されるか

| 指標 | 内容 |
|---|---|
| **BPM** | テンポを自動検出。つなぎやすい曲を把握できます。 |
| **Key (Camelot)** | ハーモニックミックス向けに、調を Camelot 表記（例 `8A`）で表示します。 |
| **Energy** | 曲の勢いを数値化。セットの流れを設計できます。 |
| **ラウドネス** | 音量レベル。実波形の描画や正規化に使われます。 |
| **類似度ベクトル** | 似た雰囲気の曲を手繰り寄せるための内部表現。 |

解析結果のうち **Key / Energy** はトラックテーブルの列として表示でき、Now Playing にも表示されます。

## いつ解析されるか

解析は「よく使う曲」だけをバックグラウンドで行います。次のいずれかがきっかけになります。

- 曲を **再生** したとき
- 右クリック → **「Analyze」** を実行したとき

解析済みの BPM / Key は、曲を編集したときに **実ファイルのタグにも書き出されます**
（BPM と InitialKey。詳しくは[ライブラリ取り込み](../import/)を参照）。

進捗はツールバーに表示されます。ライブラリ全曲を一度に解析するのではなく、
実際に使う曲に絞って解析することで、無駄なく動きます。

## 類似度選曲（Similar Digging）

右レールの **Similar** タブで、解析値をもとにした「次の一手」を提案します。

- 曲を右クリック → **「Find similar」**（または `Ctrl/Cmd + Shift + S`）で、
  **Camelot キー互換 + テンポ近接** の候補を表示します。
- 基準曲は「選択中の曲」「再生中の曲」から選べ、ピンを解除すると再生中の曲に追従します。

### 掘り進める（履歴）

候補の行から **「この曲を基準に掘る」** を選ぶと、その曲を新しい基準にして掘り進められます。

- **Back / Forward** と **パンくず** でセッション中の基準曲の履歴を行き来できます。
  パンくずをクリックするとその時点へジャンプします（履歴は Clear でリセットされます）。

### なぜ似ているか（reason チップ）

各候補には、基準曲との関係を示すチップが付きます。

- **Key** — 候補の Camelot キー（基準と違う場合は `8A → 9A` のように表示）
- **BPM** — 基準との差（`BPM +1.5` / `BPM -2.0%` など）
- **Energy** — 基準との差（`Energy +0.08` など）
- **Harmonic** — ハーモニックに互換なキーであること
- **d=** — 類似度ベクトルの距離

### 絞り込み（フィルタ）

- **Harmonic** — Camelot 互換キーのみ（BPM フィルタとは独立して効きます）
- **BPM 許容差** — 基準比での許容範囲
- **Energy close** — Energy 差 0.15 以下のみ
- **クレート内を除外** / **同じアーティストを除外** / **★★★ 以上のみ**

これらの絞り込み条件は保存され、次回起動時にも引き継がれます。

### 行の操作

各行から **Preview（試聴）/ この曲を基準に掘る / 次に再生 / Crate に追加** が行えます。
候補は Crate へドラッグ＆ドロップでも追加でき、ダブルクリックでプレビューできます。
すべて追加済みなら「Add all」は "All added" で無効化されます。

## 検索フィルタ構文

解析値は検索でも絞り込めます（テキスト検索や他のフィールド指定と AND 結合）。

```text
bpm:120-128
key:8A
key:compat:8A
energy:60-100
analyzed:no
```

- `bpm:` は単一値だと ±2 の幅で拾い、解析値を優先します（無ければ曲の BPM タグ）。
- `key:compat:8A` は **8A とハーモニックに繋がるキー**（8A / 8B / 7A / 9A）をまとめて絞り込みます。
  判定は Similar タブと同じロジックなので、両者の結果はズレません。
- `energy:` は 0〜1 でも 0〜100 でも書けます。
- `analyzed:yes` / `analyzed:no` で解析済み / 未解析を切り分けられます。

アーティストや年・レーティングでの絞り込みも含めた全体は、[検索構文](../customize/)を参照してください。

## スマートプレイリスト・AI 選曲との連携

- [スマートプレイリスト](../smart-playlists/) の条件に BPM / Key / Energy を使えます。
- [内蔵 API サーバー](../api-server/) は解析結果や類似曲も返すため、dj-curator などの AI 選曲が解析値をボーナスとして活用できます。

:::note
選曲は **メタデータ主体**（レーティング / ジャンル / 年代）で行うのが基本方針で、
BPM / Key / Energy は「あれば使うボーナス」として扱われます。
:::
