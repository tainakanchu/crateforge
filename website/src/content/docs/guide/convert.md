曲を別の音声フォーマットへ変換できます（ffmpeg を使用）。タグと埋め込みカバーアートを引き継ぎ、進捗を表示します。

> 画像は後日追加

## 変換する

1. 曲（複数選択可）を **右クリック → 「形式を変換…」**。
2. **形式・ビットレート・出力先** を選びます。
3. 必要なら「変換後にライブラリへ追加」を有効にします。
4. 変換を開始すると進捗が表示されます。

ダイアログは `Esc` で閉じられ、初期フォーカスと `Enter` 確定にも対応します。

## 対応フォーマット

| 形式 | 種別 | 備考 |
|---|---|---|
| **MP3** | 非可逆 | ビットレート指定 |
| **AAC** | 非可逆 | ビットレート指定 |
| **Opus** | 非可逆 | ビットレート指定 |
| **FLAC** | 可逆 | |
| **ALAC** | 可逆 | |
| **WAV** | 無圧縮 | |

非可逆フォーマット（MP3 / AAC / Opus）では **ビットレート** を選べます。

## 出力先とライブラリ追加

- **出力先フォルダ** を指定できます。
- 「ライブラリへ追加」を有効にすると、変換後のファイルを **出力先に置いたまま（その場参照で）** ライブラリに取り込みます（整理先フォルダの規則による再配置は行いません）。

変換時には、ライブラリのタグと埋め込みカバーアートが新しいファイルへ引き継がれます。

## 変換して置き換え

曲を **右クリック → 「変換して置き換え…」**（または変換ダイアログの「方式」で「置き換え」）を選ぶと、元ファイルの隣に同じ名前で変換し、**同じ曲のまま**（レート・再生回数・プレイリスト・編集したタグはそのまま）新しいファイルへ差し替えます。

- タグと埋め込みカバーアートは元ファイルから引き継ぎます。
- 差し替える前に新しいファイルを最後までデコードし、長さが元とほぼ同じかを確かめます。失敗した曲は元ファイルに手を付けません。
- 元ファイルは **ゴミ箱へ**（既定）か **`_replaced` フォルダに残す** を選べます（最後の選択を覚えます）。他の曲も同じファイルを参照している場合は移動しません。
- すでに変換先と同じ形式で、ビットレートも同じか低い曲（MP3 320 → MP3 320 など）はスキップします。
- 非可逆 → 非可逆（AAC → MP3 など）も変換できますが、音質が劣化するため件数を ⚠ で示します。
- 結果は件数（成功 / スキップ / 失敗）で表示し、「詳細」で曲ごとの理由を確認できます。

ローカル API（`POST /api/convert-replace`）からも実行できます（[API サーバー](../api-server/) を参照）。

## ffmpeg について

変換は **ffmpeg を外部プロセスとして利用** します。

- **Windows** — ffmpeg は同梱せず、**初回利用時に自動取得＋キャッシュ** します。
  解決順は `%LOCALAPPDATA%` のキャッシュ → （旧バージョンの同梱 resource）→ PATH → どれも無ければ上流（BtbN）からダウンロード。アプリを更新しても ffmpeg は保持されます。
- **macOS / Linux** — **PATH 上の ffmpeg** を利用します（別途インストールしておいてください）。

:::note
ffmpeg は GPL ライセンスのため同梱を避け、CLI として外部プロセスで利用しています。
:::
