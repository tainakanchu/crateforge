**スマートプレイリスト** は、条件（ルール）で中身が自動的に決まるプレイリストです。
開くたびにライブラリ全体を評価するため、常に最新の状態に保たれます。

> 画像は後日追加

## 作成と編集

- サイドバーのプレイリスト見出しの **＋ ボタン →「新規スマートプレイリスト」**（プレイリスト一覧の空白部分の右クリックでも同じメニューが出ます）で新規作成します。Rules（YAML）で定義したい場合は、同じメニューの **「Rules でスマートプレイリストを定義…」** から Rules パネルを開けます。
- 既存のスマートプレイリストは **右クリック →「条件を編集」** で条件を編集できます。

## 条件（ルール）

エディタでは、次の組み合わせでルールを定義します。

- **フィールド / 演算子 / 値** — 1 行で 1 つの条件。
- **すべて / いずれかに一致** — 複数条件を AND / OR で結合。
- **グループ** — 「グループを追加」で入れ子の条件（例: A かつ (B または C)）を作れます（3 段まで）。
- **並び替え** — 結果の並び順。
- **上限（件数制限）** — 先頭から N 件に制限。

条件に使えるフィールドには、基本のメタデータに加えて **解析値** も含まれます。

- **BPM** / **Key (Camelot)** / **Energy**
- **再生回数** / **スキップ回数** / **レーティング**（星 0〜5・0.5 刻み。検索の `rating:` と同じ数え方で、「が 3」は 3 星と 3.5 星、「が 3.5」は 3.5 星だけに一致します。3 星だけにしたいときは「3 以上」と「3.5 より小さい」を組み合わせます）/ **最終再生日時**
- 名前 / アーティスト / アルバム / アルバムアーティスト / ジャンル / グルーピング / 年 など
- **プレイリスト** — 別のプレイリストに含まれる / 含まれない（参照先がスマートなら評価結果、フォルダなら中のプレイリスト全体）。
  参照先の条件を変えると、参照しているスマートプレイリストにも反映されます。

文字列条件には「含む / 含まない / 一致 / 一致しない / で始まる / で終わる」が使えます。

### 日付の条件（過去 N 日以内）

**追加日** / **更新日** / **最終再生** では、「**が過去…以内**」「**が過去…以内でない**」で
今日を基準にした期間を指定できます（例: 追加日が過去 30 日以内、最終再生が過去 3 か月以内でない）。
期間は数値と単位（**日 / 週 / か月**）で入力します（上限は 36500 日 / 5200 週 / 1200 か月）。

- 期間は評価したその時点から数えます。評価し直すのは、プレイリストを開いたときと、ライブラリやプレイリストが
  変わったときです（直前の評価から 1 分以内なら前の結果を使います）。サイドバーの曲数は、アプリに戻ったとき
  （ウィンドウを前面にしたとき）にも数え直します。開いたままの一覧は、日付が変わっただけでは更新されないので、
  開き直すと最新になります。
- 日・週は「今から 24 時間 × 日数」前、か月はお使いのパソコンの時刻での暦の月で数えます（3 月 31 日の「過去 1 か月」は 2 月末日から）。
  ちょうど境界の時刻は「以内」に入ります。
- 日付の無い曲（一度も再生していない曲の最終再生など）は「以内」には入らず、「以内でない」に入ります
  （「含まない」「一致しない」と同じ扱い）。例えば「最終再生が過去 3 か月以内でない」は未再生の曲も含みます。
- 追加日は iTunes から取り込んだ「追加日」をそのまま使います。

### 入力の補助

- **日付条件** はネイティブの日付入力で指定できます。
- ジャンルなどの文字列条件には [CJK 字体ゆれ吸収](../customize/)（繁体字 / 簡体字 / 日本語漢字・かなの正規化）が効きます。

## フォルダ階層

スマートプレイリストも通常のプレイリストと同様、サイドバーの **フォルダ階層** に配置できます。
フォルダはクリックで折りたたみ / 展開でき、その状態は保存されて再起動後も保たれます。

フォルダを削除するときは、右クリック →「削除…」の確認ダイアログで **「フォルダだけ削除し、中身は残す」**
（中のプレイリストは 1 つ上の階層へ移動）と **「中身ごと削除」** を選べます。曲そのものはどちらでもライブラリに残ります。

:::note
iTunes XML のスマートプレイリストは、取り込み時に条件を変換します（[ライブラリ取り込み](../import/)を参照）。
既に取り込んだライブラリには、ツールバーの **「取り込み ▾」→「スマートプレイリストを復元…」** で条件だけを設定し直せます。
:::
