トラックテーブルや右ペインは、自分の使い方に合わせて細かく調整できます。設定は永続化されます。

> 画像は後日追加

## 列のカスタマイズ

- **列幅のリサイズ** — ヘッダ右端をドラッグして列幅を変更します（Genre / タグ列も全部見える幅に広げられます）。
- **列の並べ替え** — ヘッダを直接ドラッグ、またはカラムピッカー（カスタマイズメニュー）のポインタ操作で並べ替えます。
- **表示する列のトグル** — カラムピッカーで列の表示 / 非表示を切り替えます。
- **トラック番号列** — アルバム内のトラック番号「Track #」と、現在の表示順の連番「No.」の 2 種類を表示できます。

## 行高・カバー・右ペイン

- **行高** — スライダーで 32〜64px の範囲で調整します。
- **アートワーク（カバー）サイズ** — なし / 小（20px）/ 中（28px）から選べます。
- **List / Albums / Tracks ビュー** — ツールバーのセグメントで切り替えます。Albums は同じアルバムを 1 枚のカードにまとめ、クリックで中の曲一覧をその場で展開します。Tracks は 1 曲 1 枚のアート壁です。
- **右ペイン（右レール）の表示 / 非表示** — トグルで隠せます（幅は左端のドラッグで変更、ダブルクリックで既定に戻ります）。

省略表示されたセル（曲名 / アルバム / アルバムアーティスト）は、ホバーで全文をツールチップ表示します。

### Albums / Artists ビュー

- **Albums** — カードはライブラリ全体でも検索結果でもプレイリスト内でも、ツールバーの Sort に従って並びます。
  カードの下には、現在のソートキーの値（Year / Date Added / Rating / Plays）を補助表示します。
- **Artists** — アーティスト一覧はサーバー（SQLite）側で集約して返し、仮想化して描画します。
  コンピレーションは **Various Artists** にまとめ、アルバムアーティストが空の曲はアーティスト名、
  どちらも無ければ "Unknown Artist" にフォールバックします。曲数・アルバム数は Albums 表示と一致します。
  Artists ビューの Sort は **Artist / Tracks / Albums** の 3 つです。

## ツールバー

- ウィンドウ幅が狭いときは、右側のアクション群（Import XML / Add Files / Add Folder / Rip CD / Rules /
  整理先フォルダ / Export XML / 自動エクスポート / サーバーから取り寄せ）が **⋯ メニュー** に畳まれます。
  畳まれても操作の内容は同じで、検索欄の幅は確保されます。
- 右端の **`?` ボタン** でキーボードショートカット一覧を開けます（`?` キーと同じ）。

## 並べ替え（ソート）

- ソートは **表示ごと（スコープごと）に記憶** されます。ライブラリ / Inbox / 最近再生 / Albums / Artists、
  そして **プレイリストごと** に別々のソートを保持し、次に開いたときも同じ並びで表示されます。
- 通常のプレイリストを List 表示で開くと、既定は **「Playlist Order」**（プレイリストに保存された手動順）です。
  この並びのときだけ行をドラッグして曲順を入れ替えられ、`Alt` + `↑` / `↓` でも 1 つずつ移動できます
  （複数選択はまとめて移動します）。Sort メニューにも「Playlist Order」がこのときだけ現れます。
- 一覧の行はサイドバーの **プレイリストへドラッグ＆ドロップして追加** することもできます（Crate へのドロップも同じ操作です）。

## CJK 字体ゆれ吸収検索

検索ボックス・内蔵 API・スマートプレイリストでは、**繁体字 / 簡体字 / 日本語漢字・かな（ひら↔カタ）・全角半角・英大小** を正規化し、
どの字体で入力しても横断的にヒットします。強度は設定で **オフ / 軽量 / 標準** から選べます。

## 検索構文

検索は `/`（または `Ctrl + F`）でフォーカスします。クエリはスペースで分割され、各トークンが **AND** で結合されます。
`キー:値` はフィールド指定、それ以外は 名前 / アーティスト / アルバム / アルバムアーティスト / ジャンル / コメントへの部分一致です。
値に空白を含めたいときは `artist:"daft punk"` のように二重引用符で囲みます。

| 書き方 | 意味 |
|---|---|
| `daft punk` | フリーテキスト（両方を含む） |
| `artist:daft` / `artist:"daft punk"` | アーティスト名の部分一致 |
| `album:discovery` | アルバム名の部分一致 |
| `albumartist:aphex`（`album_artist:` も可） | アルバムアーティストの部分一致 |
| `genre:house` | ジャンルの部分一致 |
| `comment:classic` | コメントの部分一致 |
| `year:2018` / `year:2015-2020` | 発売年（単一 / 範囲） |
| `rating:5` / `rating:4-5` / `rating:0` | 星 0〜5（`rating:0` は未評価） |
| `bpm:128` / `bpm:120-128` | BPM（単一値は ±2。解析値を優先） |
| `key:8A` | Camelot キーの完全一致 |
| `key:compat:8A` | 8A とハーモニックに繋がるキー（8A / 8B / 7A / 9A） |
| `energy:60-100` | エネルギー（0〜1 でも 0〜100 でも可） |
| `analyzed:yes` / `analyzed:no` | 解析済み / 未解析 |

例: `artist:"daft punk" year:2001 key:compat:8A analyzed:yes`

テキスト系のフィールド指定は、フリーテキスト検索と同じ字体ゆれ吸収が効きます。
解釈できない値（`key:compat:99Z` など）は、そのままフリーテキストとして扱われます。
`bpm:` / `key:` / `energy:` / `analyzed:` は[解析](../dj-analysis/)済みの情報を参照します。

### プレイリストの中を検索する

プレイリストを開いているときは、検索ボックスの横に **「このプレイリスト」/「ライブラリ全体」** の
スコープ切り替えが出ます（既定は「このプレイリスト」）。検索してもプレイリスト表示から飛ばされることはなく、
上の検索構文はプレイリスト内検索でもそのまま使えます（スマートプレイリストでも同じです）。

## ウィンドウと表示状態の復元

- ウィンドウの **サイズ / 位置 / 最大化状態** は終了時に保存され、次回起動時に復元されます。
  ウィンドウの最小幅は **1024px** です。
- **前回の表示状態**（ライブラリ / プレイリスト / Inbox などの表示、選択していたプレイリスト、
  絞り込みタグ、右ペインの Set tools の開閉、スコープごとのソート）も復元されます。
  復元したプレイリストが見つからないときはライブラリ表示に戻ります。
- Triage / Preview / Audition はセッション限りのモードで、起動時には持ち越しません。

## キーボードショートカット

`?` キー（またはツールバーの `?` ボタン）でショートカット一覧オーバーレイを表示できます。

### 再生

| キー | 操作 |
|---|---|
| `Space` | 再生 / 一時停止 |
| `Enter` | 選択した曲を再生 |
| `J` | 前の曲 |
| `K` | 次の曲 |
| `Shift` + `←` | 5 秒戻る |
| `Shift` + `→` | 5 秒進む |
| `S` | シャッフル切り替え |
| `R` | リピート切り替え |
| `Ctrl` + `↑` | 音量を上げる |
| `Ctrl` + `↓` | 音量を下げる |

### Audition / Preview

| キー | 操作 |
|---|---|
| `A` | Audition モード切り替え |
| `1` | 25% 位置へジャンプ（Audition 時） |
| `2` | 50% 位置へジャンプ（Audition 時） |
| `3` | 75% 位置へジャンプ（Audition 時） |
| `Home` | 曲の先頭へ（Audition 時） |
| `End` | 曲の終盤（末尾 −3 秒）へ（Audition 時） |
| `Alt` + `←` | 15 秒戻る（Audition 時） |
| `Alt` + `→` | 15 秒進む（Audition 時） |
| `Esc` | Preview を終了して元の曲へ復帰 |

### ナビゲーション・検索

| キー | 操作 |
|---|---|
| `/` | 検索にフォーカス |
| `Ctrl` + `F` | 検索にフォーカス |
| `Ctrl` + `L` | ライブラリへ戻る（検索クリア） |
| `Esc` | 検索 / 入力を抜ける・ダイアログを閉じる |

### リスト操作

| キー | 操作 |
|---|---|
| `↑` / `↓` | 選択を上下に移動 |
| `Shift` + `↑` / `↓` | 選択範囲を拡張 |
| `Ctrl` + `A` | すべて選択 |
| `Ctrl` + `I` | 選択した曲を編集（Get Info） |
| `Alt` + `↑` | 選択曲を 1 つ上へ（プレイリストを Playlist Order で表示中） |
| `Alt` + `↓` | 選択曲を 1 つ下へ（プレイリストを Playlist Order で表示中） |
| ドラッグ＆ドロップ | 行をドラッグ: プレイリスト内で並べ替え / サイドバーのプレイリスト・Crate へ追加 |
| `≣`（アプリケーションキー） | コンテキストメニュー（フォーカス行基準で表示） |

### 選曲ワークベンチ（右ペイン）

| キー | 操作 |
|---|---|
| `Ctrl` + `]` | 右ペインを表示 |
| `Ctrl` + `1` | Now Playing タブ |
| `Ctrl` + `2` | Up Next タブ |
| `Ctrl` + `3` | Crate タブ |
| `Ctrl` + `4` | Similar タブ |
| `Ctrl` + `Shift` + `S` | 選択曲を Similar の基準にする |
| `Ctrl` + `Shift` + `C` | 選択曲を Crate に追加 |

### Inbox / Triage

| キー | 操作 |
|---|---|
| `T` | Inbox で Triage を開始 |
| `Space` | プレビュー再生 / 一時停止（Triage 中） |
| `J` / `↓` | 次の曲（Triage 中） |
| `K` / `↑` | 前の曲（Triage 中） |
| `1`〜`5` | レーティング（Triage 中） |
| `C` | Crate に追加（Triage 中） |
| `D` / `Enter` | 処理済みにして次へ（Triage 中） |
| `S` | あとで（スキップ）（Triage 中） |
| `Esc` | Triage 終了 → Inbox リスト |

### ヘルプ

| キー | 操作 |
|---|---|
| `?` | このショートカット一覧を表示 |
