**智慧型播放清單** 是依條件（規則）自動決定內容的播放清單。
每次開啟都會評估整個音樂庫，因此始終保持最新狀態。

## 建立與編輯

- 用側邊欄的 **🎛 按鈕** 新增。
- 既有的智慧型播放清單可用 **右鍵 →「条件を編集」（編輯規則）** 來編輯條件。

## 條件（規則）

在編輯器中，以下列組合定義規則。

- **欄位 / 運算子 / 值** — 1 列為 1 個條件。
- **全部 / 任一符合** — 以 AND / OR 結合多個條件。
- **群組** — 以「新增群組」建立巢狀條件（例：A 且 (B 或 C)），最多 3 層。
- **排序** — 結果的排列順序。
- **上限（件數限制）** — 從開頭限制為 N 件。

可用於條件的欄位，除了基本中繼資料外，還包含 **解析值**。

- **BPM** / **Key (Camelot)** / **Energy**
- **播放次數** / **略過次數** / **評等**（星等 0〜5，以 0.5 為單位。與搜尋的 `rating:` 算法相同：「為 3」符合 3 星與 3.5 星，「為 3.5」只符合 3.5 星。只要 3 星時，請組合「3 以上」與「小於 3.5」）/ **最後播放時間**
- 名稱 / 演出者 / 專輯 / 專輯演出者 / 類型 / 分組 / 年份 等
- **播放清單** — 包含 / 不包含於其他播放清單（參照對象為智慧型時使用評估結果，資料夾則涵蓋其中所有播放清單）。
  變更參照對象的條件，也會反映到參照它的智慧型播放清單。

字串條件可使用「包含 / 不包含 / 等於 / 不等於 / 開頭為 / 結尾為」。

### 日期條件（過去 N 天內）

**加入日期** / **修改日期** / **最後播放** 可用「**が過去…以内**」（在過去…以內）與「**が過去…以内でない**」（不在過去…以內）
指定以今天為基準的期間（例：加入日期在過去 30 天內、最後播放不在過去 3 個月內）。
期間以數值與單位（**日 天 / 週 週 / か月 個月**）輸入（上限為 36500 天 / 5200 週 / 1200 個月）。

- 期間從評估的當下起算。開啟播放清單時，以及音樂庫或播放清單變更時會重新評估（距上次評估不到 1 分鐘則沿用先前結果）。
  側邊欄的曲數在回到應用程式時（視窗移到前景時）也會重新計算。保持開啟的清單不會只因日期改變而更新，重新開啟即可取得最新內容。
- 天與週為「現在往前 24 小時 × 天數」，月則以電腦本地時間的日曆月計算（3 月 31 日的「過去 1 個月」從 2 月底開始）。
  剛好落在邊界的時刻算在「以內」。
- 沒有日期的曲目（例如從未播放過的曲目的最後播放）不符合「以內」，但符合「不在以內」
  （與「不包含」「不等於」相同）。例如「最後播放不在過去 3 個月內」也包含未播放的曲目。
- 加入日期直接使用從 iTunes 匯入的「加入日期」。

### 輸入輔助

- **日期條件** 可用原生的日期輸入指定。
- 類型等字串條件適用 [CJK 字體差異吸收](../customize/)（繁體字 / 簡體字 / 日文漢字與假名的正規化）。

## 資料夾階層

智慧型播放清單與一般播放清單相同，可放置於側邊欄的 **資料夾階層** 中。
資料夾可點選摺疊 / 展開，且該狀態會被保存，重新啟動後仍維持。

刪除資料夾時（右鍵 →「削除…」），確認對話框可選擇 **「フォルダだけ削除し、中身は残す」（只刪除資料夾，其中的播放清單移到上一層）**
或 **「中身ごと削除」（連同內容一起刪除）**。無論哪種，曲目本身都會留在音樂庫中。

:::note
iTunes XML 的智慧型播放清單會在匯入時轉換條件（請參閱[音樂庫匯入](../import/)）。
對於已匯入的音樂庫，可用工具列的 **「iTunes XML からスマートプレイリストを復元…」（從 iTunes XML 還原智慧型播放清單…）** 只重新設定條件。
:::
