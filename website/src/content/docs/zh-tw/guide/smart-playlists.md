**智慧型播放清單** 是依條件（規則）自動決定內容的播放清單。
每次開啟都會評估整個音樂庫，因此始終保持最新狀態。

## 建立與編輯

- 用側邊欄的 **🎛 按鈕** 新增。
- 既有的智慧型播放清單可用 **右鍵 → 編輯規則** 來編輯條件。

## 條件（規則）

在編輯器中，以下列組合定義規則。

- **欄位 / 運算子 / 值** — 1 列為 1 個條件。
- **全部 / 任一符合** — 以 AND / OR 結合多個條件。
- **群組** — 以「新增群組」建立巢狀條件（例：A 且 (B 或 C)），最多 3 層。
- **排序** — 結果的排列順序。
- **上限（件數限制）** — 從開頭限制為 N 件。

可用於條件的欄位，除了基本中繼資料外，還包含 **解析值**。

- **BPM** / **Key (Camelot)** / **Energy**
- **播放次數** / **略過次數** / **評等**（星等 0〜5，以 0.5 為單位）/ **最後播放時間**
- 名稱 / 演出者 / 專輯 / 專輯演出者 / 類型 / 分組 / 年份 等
- **播放清單** — 包含 / 不包含於其他播放清單（參照對象為智慧型時使用評估結果，資料夾則涵蓋其中所有播放清單）。
  變更參照對象的條件，也會反映到參照它的智慧型播放清單。

字串條件可使用「包含 / 不包含 / 等於 / 不等於 / 開頭為 / 結尾為」。

### 輸入輔助

- **日期條件** 可用原生的日期輸入指定。
- 類型等字串條件適用 [CJK 字體差異吸收](../customize/)（繁體字 / 簡體字 / 日文漢字與假名的正規化）。

## 資料夾階層

智慧型播放清單與一般播放清單相同，可放置於側邊欄的 **資料夾階層** 中。
資料夾可點選摺疊 / 展開，且該狀態會被保存，重新啟動後仍維持。

:::note
iTunes XML 的智慧型播放清單會在匯入時轉換條件（請參閱[音樂庫匯入](../import/)）。
對於已匯入的音樂庫，可用工具列的 **「iTunes XML からスマートプレイリストを復元…」（從 iTunes XML 還原智慧型播放清單…）** 只重新設定條件。
:::
