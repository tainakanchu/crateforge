曲目表格與右側欄都能依你的使用習慣細部調整。設定會被保存。

> 截圖稍後補上

## 欄的自訂

- **調整欄寬** — 拖曳標頭右緣即可變更欄寬（也能把 Genre / 標籤欄拉寬到完整顯示）。
- **欄的排序** — 直接拖曳標頭，或在欄位挑選器（自訂選單）中以指標操作排序。
- **切換顯示的欄** — 在欄位挑選器中切換欄的顯示 / 隱藏。
- **曲目編號欄** — 可顯示兩種：專輯內的曲目編號「Track #」，以及依目前顯示順序的流水號「No.」。

## 列高、封面、右側欄

- **列高** — 以滑桿在 32〜64px 範圍內調整。
- **封面圖（封面）尺寸** — 可從 無 / 小（20px）/ 中（28px）選擇。
- **List / Albums / Tracks 檢視** — 以工具列的分段控制切換。Albums 會把同一張專輯彙整為一張卡片，點選後就地展開其中的曲目清單。Tracks 則是一曲一卡的封面牆。
- **右側欄的顯示 / 隱藏** — 可用切換鈕隱藏（拖曳左緣可調整寬度，雙擊可還原為預設）。

被省略顯示的儲存格（曲名 / 專輯 / 專輯演出者），只要滑鼠懸停就會以工具提示顯示全文。

### Albums / Artists 檢視

- **Albums** — 無論是整個音樂庫、搜尋結果，還是播放清單之內，卡片都會依工具列的 Sort 排序。
  卡片下方會以輔助行顯示目前排序鍵的值（Year / Date Added / Rating / Plays）。
- **Artists** — 演出者清單改由伺服器端（SQLite）彙整後回傳，並以虛擬化繪製。
  合輯會彙整為 **Various Artists**；專輯演出者為空時退回演出者名稱，兩者皆無時退回 "Unknown Artist"。
  曲目數與專輯數會與 Albums 檢視一致。Artists 檢視的 Sort 只有 **Artist / Tracks / Albums** 三種。

## 工具列

- 視窗寬度較窄時，右側的動作群（Import XML / Add Files / Add Folder / Rip CD / Rules /
  整理目標資料夾 / Export XML / 自動匯出 / 從伺服器取得）會收折進 **⋯ 選單**。
  收折後操作內容完全相同，且搜尋框會保留最小寬度。
- 最右側的 **`?` 按鈕** 可開啟鍵盤快捷鍵一覽（與 `?` 鍵相同）。

## 排序

- 排序會 **依檢視（依範圍）分別記住**。音樂庫 / Inbox / 最近播放 / Albums / Artists，
  以及 **每個播放清單** 都各自保留排序，下次開啟時仍是同樣的順序。
- 以 List 檢視開啟一般播放清單時，預設為 **「Playlist Order」**（播放清單中保存的手動順序）。
  只有在這個順序下才能拖曳列來調整曲序，也可用 `Alt` + `↑` / `↓` 逐一移動（多選會整批移動）。
  Sort 選單也只有在此時才會出現「Playlist Order」。
- 清單的列還可 **拖放到側邊欄的播放清單以加入**（拖放到 Crate 也是同樣的操作）。

## CJK 字體差異吸收搜尋

在搜尋框、內建 API、智慧型播放清單中，會將 **繁體字 / 簡體字 / 日文漢字與假名（平假名↔片假名）/ 全形半形 / 英文大小寫** 正規化，
無論用哪種字體輸入都能橫跨命中。強度可在設定中從 **關閉 / 輕量 / 標準** 選擇。

## 搜尋語法

搜尋可用 `/`（或 `Ctrl + F`）取得焦點。查詢會以空格分割，各 token 以 **AND** 結合。
`鍵:值` 為欄位指定，其餘則是對 名稱 / 演出者 / 專輯 / 專輯演出者 / 類型 / 註解 的部分比對。
若值中要包含空格，請用雙引號包住，例如 `artist:"daft punk"`。

| 寫法 | 意義 |
|---|---|
| `daft punk` | 自由文字（同時包含兩者） |
| `artist:daft` / `artist:"daft punk"` | 演出者名稱的部分比對 |
| `album:discovery` | 專輯名稱的部分比對 |
| `albumartist:aphex`（也可用 `album_artist:`） | 專輯演出者的部分比對 |
| `genre:house` | 類型的部分比對 |
| `comment:classic` | 註解的部分比對 |
| `year:2018` / `year:2015-2020` | 發行年（單一 / 範圍） |
| `rating:5` / `rating:4-5` / `rating:0` | 星等 0〜5（`rating:0` 為未評分） |
| `bpm:128` / `bpm:120-128` | BPM（單一值為 ±2；優先採用解析值） |
| `key:8A` | Camelot 鍵的完全比對 |
| `key:compat:8A` | 與 8A 和聲相容的鍵（8A / 8B / 7A / 9A） |
| `energy:60-100` | 能量（0〜1 或 0〜100 皆可） |
| `analyzed:yes` / `analyzed:no` | 已解析 / 未解析 |

範例：`artist:"daft punk" year:2001 key:compat:8A analyzed:yes`

文字類的欄位指定同樣會套用自由文字搜尋的字體差異吸收。
無法解讀的值（例如 `key:compat:99Z`）會照舊當成自由文字處理。
`bpm:` / `key:` / `energy:` / `analyzed:` 參照的是[解析](../dj-analysis/)資料。

### 在播放清單之內搜尋

開啟播放清單時，搜尋框旁會出現 **「這個播放清單」/「整個音樂庫」** 的範圍切換（預設為這個播放清單）。
輸入搜尋不會再把你彈回音樂庫檢視，且上述語法在播放清單內搜尋時完全一樣可用（智慧型播放清單亦同）。

## 視窗與顯示狀態的還原

- 視窗的 **大小 / 位置 / 最大化狀態** 會在結束時保存，並於下次啟動時還原。
  視窗的最小寬度為 **1024px**。
- **上次的顯示狀態** 也會還原：檢視（音樂庫 / 播放清單 / Inbox 等）、選取中的播放清單、
  篩選標籤、右側欄 Set tools 的開合，以及依範圍分別保存的排序。
  若還原的播放清單已不存在，會退回音樂庫檢視。
- Triage / Preview / Audition 是僅限本次工作階段的模式，不會延續到下次啟動。

## 鍵盤快捷鍵

按 `?` 鍵（或工具列的 `?` 按鈕）可顯示快捷鍵一覽的覆蓋層。

### 播放

| 按鍵 | 操作 |
|---|---|
| `Space` | 播放 / 暫停 |
| `Enter` | 播放選取的曲目 |
| `J` | 上一首 |
| `K` | 下一首 |
| `Shift` + `←` | 倒退 5 秒 |
| `Shift` + `→` | 快轉 5 秒 |
| `S` | 切換隨機播放 |
| `R` | 切換重複播放 |
| `Ctrl` + `↑` | 提高音量 |
| `Ctrl` + `↓` | 降低音量 |

### Audition / Preview

| 按鍵 | 操作 |
|---|---|
| `A` | 切換 Audition 模式 |
| `1` | 跳至 25% 位置（Audition 時） |
| `2` | 跳至 50% 位置（Audition 時） |
| `3` | 跳至 75% 位置（Audition 時） |
| `Home` | 跳至曲目開頭（Audition 時） |
| `End` | 跳至曲目尾段（結尾 −3 秒）（Audition 時） |
| `Alt` + `←` | 倒退 15 秒（Audition 時） |
| `Alt` + `→` | 快轉 15 秒（Audition 時） |
| `Esc` | 結束 Preview 並回到原本的曲目 |

### 導覽與搜尋

| 按鍵 | 操作 |
|---|---|
| `/` | 焦點移至搜尋 |
| `Ctrl` + `F` | 焦點移至搜尋 |
| `Ctrl` + `L` | 返回音樂庫（清除搜尋） |
| `Esc` | 離開搜尋 / 輸入、關閉對話框 |

### 清單操作

| 按鍵 | 操作 |
|---|---|
| `↑` / `↓` | 上下移動選取 |
| `Shift` + `↑` / `↓` | 擴展選取範圍 |
| `Ctrl` + `A` | 全選 |
| `Ctrl` + `I` | 編輯選取的曲目（Get Info） |
| `Alt` + `↑` | 將選取曲目往上移一格（以 Playlist Order 顯示播放清單時） |
| `Alt` + `↓` | 將選取曲目往下移一格（以 Playlist Order 顯示播放清單時） |
| 拖放 | 拖曳列：在播放清單內重新排序 / 加入側邊欄的播放清單或 Crate |
| `≣`（應用程式鍵） | 內容選單（以焦點列為基準顯示） |

### 選曲工作台（右側欄）

| 按鍵 | 操作 |
|---|---|

| `Ctrl` + `3` | Crate 分頁 |
| `Ctrl` + `4` | Similar 分頁 |
| `Ctrl` + `Shift` + `S` | 以選取曲目作為 Similar 的基準 |

### Inbox / Triage

| 按鍵 | 操作 |
|---|---|
| `T` | 在 Inbox 開始 Triage |
| `Space` | 預覽播放 / 暫停（Triage 中） |
| `J` / `↓` | 下一首（Triage 中） |
| `K` / `↑` | 上一首（Triage 中） |
| `1`〜`5` | 評分（Triage 中） |
| `C` | 加入 Crate（Triage 中） |
| `D` / `Enter` | 標記為已處理並前往下一首（Triage 中） |
| `S` | 稍後（略過）（Triage 中） |
| `Esc` | 結束 Triage → 回到 Inbox 清單 |
